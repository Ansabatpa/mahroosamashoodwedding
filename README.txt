Optional: District Thin
If you have a legally licensed copy of District Thin, save its web files here with these exact names:
  DistrictThin.woff2   (preferred)
  DistrictThin.woff
  DistrictThin.ttf
The site uses them automatically. Without them it shows Jost Thin/Light (Google Fonts, free to use), which looks very similar.
Check the font's licence allows website embedding before uploading it to a public site.
